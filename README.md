# Кадр (muzz)

Статический прототип платформы «Кадр» — кастинги, проекты, профили.

## Локально

```bash
python3 -m http.server 8765
```

Открыть [http://localhost:8765](http://localhost:8765).

## GitHub Pages

После push в `main` сайт публикуется автоматически:

**https://andrewantoshkin.github.io/muzz/**

В настройках репозитория: **Settings → Pages → Build and deployment → GitHub Actions**.
